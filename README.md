# Santiago Bassani - Personal Portfolio

A sleek, responsive, and modern personal portfolio website built with **Astro** and **React**. Designed to showcase my projects, skills, and background as a Fullstack Software Developer.

## Features

- **Modern UI/UX**: Clean aesthetic with dynamic glassmorphism and smooth micro-animations.
- **Light/Dark Mode**: Fully responsive theme toggle that remembers your preference.
- **Responsive Design**: Mobile-first approach ensuring a great experience on any device size.
- **Component-Driven**: Built using reusable Astro components.

## Tech Stack

- [Astro](https://astro.build/) - Web framework for building fast, content-focused websites.
- [React](https://reactjs.org/) - For dynamic UI components.
- HTML5 & CSS3 - For styling, using CSS Variables for theming.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/sbassan1/portfolio.git
   ```
2. Navigate to the project directory:
   ```sh
   cd portfolio
   ```
3. Install dependencies:
   ```sh
   npm install
   ```
4. Start the development server:
   ```sh
   npm run dev
   ```
   The site will be available at `http://localhost:4321`.

### Build for Production
To create a production-ready build:
```sh
npm run build
```
This generates the optimized static assets in the `dist/` directory, ready to be deployed to any static hosting provider.
